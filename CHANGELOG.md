## [3.8.1] - 2026-11-25

### Added
- First public release of the GTM Engineer OS template: a multi-client operating system for running
  Instantly cold email clients from one repo with Claude Code. Shared brain (skills, wiki, frameworks,
  best practices, playbooks), one isolated folder per client, per-client Instantly API access through
  `.claude/bin/instantly.sh`, and a safety guard that gates every write.
